# AI-Based Network Intrusion Detection System

## Overview

This project implements a real-time **Network Intrusion Detection System (NIDS)** using Python, Scapy, and Machine Learning. The system captures live network packets, extracts traffic features, classifies suspicious activity, and generates alerts.

## Features

* Live packet capture from network interfaces
* Feature extraction from TCP/IP packets
* Machine-learning based attack detection
* Real-time intrusion alerts
* Logging and reporting
* Modular and extensible architecture

## Tech Stack

* Python 3.11+
* Scapy
* Pandas
* Scikit-learn
* Joblib
* Kali Linux

## Project Structure

```text
src/
 ├── capture/        # Packet capture
 ├── features/       # Feature extraction
 ├── model/          # Model training
 ├── detection/      # Real-time detection
 ├── alerts/         # Alert management
 └── utils/          # Helper utilities
```
