# Phase 6 – Alert Monitoring & Detection Statistics

## 1. Overview

Phase 6 extends the AI-Based Network Intrusion Detection System with an alert monitoring and statistics component.

Phase 5 introduced real-time machine-learning-based traffic detection and suspicious traffic alert generation. Phase 6 builds on that functionality by reading the generated alert log, parsing individual alert records, and calculating useful detection statistics.

The objective is to transform raw alert entries into structured monitoring information that can be used to understand the behavior of the detection system.

---

## 2. Objectives

The main objectives of Phase 6 were:

- Read alerts generated by the Phase 5 alert manager.
- Parse alert log entries into structured records.
- Calculate the total number of alerts.
- Determine protocol distribution.
- Determine source IP distribution.
- Determine destination IP distribution.
- Calculate packet-length statistics.
- Display the monitoring results in a human-readable format.
- Validate the module using real alert data and an empty-alert test case.
